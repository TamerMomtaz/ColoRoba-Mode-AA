Usage Guidelines

Best practices for implementing the color system

✓ DO

  • Use White or Light Gray text on Blue dark backgrounds
  • Use Medium Light Teal on Blue backgrounds for emphasis
  • Use Black or Dark Gray text on Cream/White backgrounds
  • Use Bronze Gold for buttons on both modes
  • Maintain 2px borders for selected states
  • Use Light Beige sections for input containers

✗ DON'T

  • Never use Medium Teal text on light backgrounds
  • Don't use insufficient contrast ratios (below 4.5:1)
  • Avoid mixing Bronze variants inconsistently
  • Don't use dark text on dark backgrounds
  • Never skip accessibility testing
  • Avoid overusing bright accent colors

✓ Dark Mode Best Practices

  • Deep Navy Blue (#102a43) / Dark Blue-Gray (#486581) for main backgrounds
  • Medium Blue-Gray (#829ab1) for cards and panels
  • Medium Light Teal (#66b2b2) for selections
  • Bronze Gold (#B8904A) for primary actions
  • White (#FFFFFF) for primary text

✓ Light Mode Best Practices

  • Warm Cream (#F5F1E8) for page backgrounds
  • Pure White (#FFFFFF) for cards and inputs
  • Light Beige (#E8E3D8) for form sections
  • Bronze Gold (#B8904A) for accents
  • Black (#000000) for primary text
